# React + Vite Template

React 19 SPA with Vite, TypeScript, and Tailwind CSS.

## Stack

- **React 19** with hooks
- **Vite** for fast development
- **TypeScript** for type safety
- **Tailwind CSS** for styling
- **React Router** for routing
- **Vitest** for testing

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:5173
```

## Development

```bash
# Run tests
npm test

# Run tests with UI
npm run test:ui

# Run linting
npm run lint

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

│   ├── App.tsx         # Root component
